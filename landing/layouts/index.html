THE WORKFLOW / 01

From file to field
and back again.

Work with record objects while rmarc handles the MARC wire format. The same reader and writer surface supports an ordinary scan or optional read-ahead for expensive sources.

Explore the API guide ↗
catalog.pyPYTHON
from rmarc import MARCReader, MARCWriter

with open("records.mrc", "rb") as source:
    with open("selected.mrc", "wb") as target:
        writer = MARCWriter(target)
        for record in MARCReader(source):
            if record.title:
                writer.write(record)
        writer.close()
